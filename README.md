# Xiaobai DesktopPet

Meet Guang Xiaobai (光晓白), your little desktop companion for Windows.

Built with Python and PySide6, Xiaobai lives in a transparent, always-on-top window. Drag her around your desktop, let her snap to screen edges, and hover over her to check your remaining Codex 5-hour and weekly usage limits.

Features include background usage updates, a system tray menu, adjustable size, optional gentle floating animation, and launch at startup.

The current version uses PNG rendering and is available as a standalone Windows executable—no separate Python installation required. Codex usage tracking requires Codex to be installed and signed in locally.

Live2D support is planned for a future release.
