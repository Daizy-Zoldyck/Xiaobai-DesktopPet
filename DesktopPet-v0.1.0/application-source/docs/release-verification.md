验证日期：2026-09-30；目标平台 Windows x64。

- 源码的 17 项测试通过，包含原有交互/额度测试和打包路径、自启动命令测试。
- 单文件 EXE 复制到没有项目源码的目录后，在不含 Python 的 PATH 下正常运行并退出（退出码 0）。
- 内置人物 PNG、真实透明通道、7 档图标、透明置顶窗口加载成功。

- EXE 开机启动命令指向真正的 EXE，而非 Python 或临时解压文件。未实际重启电脑测试。

尚未验证：其他电脑、多屏跨屏、所有 DPI 配置、全天持续运行。
