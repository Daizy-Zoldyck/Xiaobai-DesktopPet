DesktopPet v0.1.0 · Windows x64 PNG 桌宠

双击 DesktopPet-v0.1.0.exe 即可运行，无需单独安装 Python。
首次打开需要几秒钟解压内置运行环境。人物和图标已嵌入 EXE，可单独复制此文件。

操作：
- 悬停人物：查看 Codex 5 小时与周额度。
- 左键拖动：移动人物，接近屏幕边缘时吸附。
- 单击：短暂轻跳。
- 右键人物或托盘图标：刷新、大小、轻微浮动、吸附、开机启动、恢复位置、退出。
- 单击托盘图标：显示或隐藏人物。

额度每 5 分钟后台读取一次，需要本机已安装并登录 Codex。
没有 Codex 或网络不可用时，宠物仍能运行，额度显示暂不可用或旧数据。
额度高低不会自动触发动画或影响你的使用决策。

设置与日志位置：%LOCALAPPDATA%\DesktopPet
开机启动默认关闭。如曾使用 Python 版，请先退出旧宠物；切换后需要在 EXE 版菜单中重新设置开机启动。
首次运行 EXE 使用默认配置，旧 Python 版的设置仍保留在原项目 runtime 文件夹。
将 EXE 放在固定目录后再启用开机启动；移动文件后重新设置该选项。

此版使用 AI 辅助处理的透明 PNG，不包含 Live2D，也未进行拆图绑定。
已检查本机启动与额度读取，其他电脑、多屏及全天运行仍需后续验证。
